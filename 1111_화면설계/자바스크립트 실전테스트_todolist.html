자바스크립트 실전테스트_todolist

오늘의 일정 구현하기
1. 입력폼과 '추가'버튼, '글삭제'버튼을 작성
2. 입력폼에 글입력하고 '추가'버튼 클릭시 아래 목록으로 내용 출력
3. 출력된 내용 옆 '삭제'버튼 추가
4. '삭제'버튼 클릭시 해당 글 삭제
5. 해당 목록글 클릭시 동그란 체크박스 체크 및 '취소선' 표시
6. '글삭제'버튼 클릭시 전체 글 삭제

오늘의 할일 - todolist(입력,출력,삭제)
